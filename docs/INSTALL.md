# Install the experimental launcher

**Loading and shader compilation have been observed; gameplay is unverified. The latest test passed shaders, then crashed with CE-108255-1.** This guide reproduces the tested configuration for further investigation. It does not promise a working game session.

## 1. Obtain the inputs

Use the files listed below. The installer refuses mismatched hashes instead of silently mixing versions.

- **This repository**, at the tag `v0.1.0-experimental`.
- **ReSkate-PS5-bundle.zip**, from this project's matching release. Unzip it beside `install.py`; the result must contain `bundle/title/eboot.bin` and `bundle/runtime/launch.txt`.
- **WoWForever-PS5.zip v0.1.0**, directly from [BeLikeBrett/WoWPS5](https://github.com/BeLikeBrett/WoWPS5/releases/tag/v0.1.0). Keep it zipped. SHA-256: `c09926955428d67b5a90db7f16fde5a162b6057d388d8579365a38123d1e7df9`. Version 0.1.1 is a different input. No WoW game files or installation are needed.
- **Your compatible ReSkate PC folder**, containing `Skate.exe`, `ReSkate.dll`, `Data/`, and the dependencies from ReSkate 2.0.5. Use the [official ReSkate project](https://github.com/Dingo-Shenanigans/ReSkate) to prepare your own Steam copy. Tested game build: `25414733`. `Skate.exe` SHA-256: `fbce74d5e28ef525dbba2cb4adbebc13405bdbd88f31bc940bca45e4ae88b8f9`.
- **Your local content cache**, normally `%LOCALAPPDATA%\ReSkate\cache\25414733`. This is generated by ReSkate on the PC. It is different from the PS5 shader cache. The installer selects 205 known content-cache files by manifest and checks their hashes. The release does not provide this game-derived content.
- **Your Windows SDK x64 `d3dcompiler_47.dll`**. Tested version: `10.0.26100.7705`, 4,741,488 bytes, SHA-256 `a05f99734f7c4822fefc12b367af21fd0976ed6608752fb1e1e80b6ece7ecbbb`. A typical path is `C:\Program Files (x86)\Windows Kits\10\Redist\D3D\x64\d3dcompiler_47.dll`. The project does not distribute this Microsoft file. Other versions have not been qualified.

If you cannot obtain matching inputs through your own legitimate installation, stop. Do not substitute arbitrary DLL downloads or disable security software. A hash mismatch is useful compatibility information, not a reason to remove the check.

## 2. Prepare the console

Activate your existing jailbreak and homebrew enabler. Enable FTP (commonly port 2121), and ensure your homebrew manager can register app directories. Keep the PC and PS5 on a trusted private LAN. FTP is unencrypted; do not expose its port to the Internet.

Reserve at least 20 GiB on internal storage, with extra room for caches. Close any running game and leave the PS5 at its home screen. The installer cannot reliably detect a running ReSkate process: `--console-at-home` is your confirmation that it is closed.

This project does not install a jailbreak, change firmware, modify global console databases, or configure your router.

## 3. Validate locally

Open a terminal in the repository folder. Python 3.11 or newer is required. No pip dependencies are needed.

```powershell
python install.py --base "D:\Downloads\WoWForever-PS5.zip" --game "D:\Games\ReSkate" --cache "$env:LOCALAPPDATA\ReSkate\cache\25414733" --compiler "C:\Program Files (x86)\Windows Kits\10\Redist\D3D\x64\d3dcompiler_47.dll"
```

Change the paths to yours. On Linux/macOS, use your own mounted input paths with `python3`; the script uses only the standard library. Cross-platform logic is supported, but the complete installation was not tested on every host OS.

Validation reads roughly 14 GiB and can take several minutes. It checks the base ZIP, selected game files, content cache, title, patched DLLs, and compiler. No FTP connection occurs without `--install`. A successful dry run confirms file compatibility, not that your PS5 can run the game.

## 4. Copy

Repeat the same command, adding:

```text
--host 192.168.1.50 --install --console-at-home
```

Replace `192.168.1.50` with your PS5's private IPv4 address. Add `--port PORT` only if FTP uses another port. Anonymous FTP and the PS5 `SELF` command are expected.

All writes are confined to `/data/reskate/` and `/data/homebrew/PPSA99223/`. The runtime's synthetic Windows user remains `wowps5` to match its clean registry seed. That name does not mean it shares the WoW installation.

Each file is uploaded to a temporary name, read back, checked with SHA-256, and renamed into place. Files already present are also hashed before skipping. Keep the application closed until the entire copy succeeds. The title metadata is installed last to reduce the chance of a partially copied app appearing launchable.

After interruption, reactivate the console's services and rerun the same command. Completed files can be reused; an interrupted file restarts. There is no size-only shortcut or unverified partial-file resume. For large game files, readback noticeably increases transfer time.

## 5. Register and launch

Use your homebrew manager's normal app discovery or registration flow for `/data/homebrew/PPSA99223`. The tile should say **ReSkate** and show a blue **RE** icon. Select it from the PS5 home screen.

The installer does not invoke a jailbreak payload, edit the app database, or auto-launch the title. Registration varies with the homebrew manager and firmware. Do not reuse the WoW title ID.

Expect a loading screen and potentially lengthy shader work. A frozen count, a returned home screen, or a console reboot are known failure modes. There is currently no verified route from this build to stable gameplay.

## Existing installations

The installer recognizes only installations carrying its own `.reskate-installer` marker in **each** destination: `/data/reskate` and `/data/homebrew/PPSA99223`. Both are checked independently before any writes. It refuses the earlier hand-installed prototype and any unknown use of either directory.

Do not create the marker by hand to bypass this check. Back up any desired ReSkate saves and caches, then use your homebrew manager and FTP client to remove **only the conflicting ReSkate installation**, verifying the two exact paths yourself. A clean installation can then proceed. Automated migration of the private prototype is intentionally not included.

## Removal and recovery

Fully close ReSkate first. Remove its tile through your homebrew manager, then remove `/data/homebrew/PPSA99223` and `/data/reskate` if you no longer need them. The latter contains your ReSkate game copy, prefix, saves, and caches; back up what you want before deleting it. Never remove `/data/wowps5` or `PPSA99220` as part of ReSkate cleanup.

The PC installation is read only. A failed upload can leave `.reskate-part` files inside the two ReSkate directories; rerunning the installer replaces them.
